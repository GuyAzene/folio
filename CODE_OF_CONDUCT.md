# Code of conduct

Folio follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
in its issues, pull requests and anywhere else it is discussed: be respectful and constructive,
and leave out harassment, personal attacks and other people's private information.

To report a problem, use **Report content** on the comment, issue or pull request. The
maintainer may edit or remove what breaks this code, and block whoever wrote it.
